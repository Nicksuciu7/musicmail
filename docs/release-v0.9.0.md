# MusicMail v0.9.0 — Local Beta

The first local beta and portfolio snapshot of MusicMail, a music-industry discovery, CRM and outreach tool for independent musicians.

- Shared discovery and structured music entities with filters.
- Private network, contacts, notes, lists and follow-ups.
- CSV import/export and personalised email previews.
- Fictional, clearly labelled demo contacts; no delivery from demo mode.
- Production build, typecheck, lint, 24 unit tests, 5 browser tests and PostgreSQL integration checks pass. Dependency audit reports zero vulnerabilities at verification time.

Live Supabase verification and live Gmail OAuth/send verification remain pending. This release is not production-ready. UX simplification is planned before v1.0.0, along with production deployment and security/privacy verification.
